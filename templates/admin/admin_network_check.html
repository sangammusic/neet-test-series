How to read this

1. Your IP. Search "what is my IP" on the same phone. It must match {{ resolved }} above. If the same IP shows up for every phone you try (an address that is not yours), the rate limits would treat all students as one person. Fix: on Render, add the setting CLIENT_IP_HEADER with the header name that holds your real IP (try True-Client-IP or CF-Connecting-IP) and check again.

2. https. {% if is_secure %}Good: the connection is seen as https, so login cookies are marked Secure. {% else %}The connection is NOT seen as https. Logins may not stick. On Render this should say yes; if you are on your own computer it is normal.{% endif %}

3. Host. Forms are accepted only from {{ seen['Host header'] }}. If your site opens on two addresses (for example with and without www), put both in the ALLOWED_HOSTS setting.
